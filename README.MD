# Vulnerable Security Lab

⚠️ WARNING: This repository intentionally contains vulnerable code.

This project exists exclusively for:
- SAST testing
- DAST testing
- Dependency scanning
- Secret scanning
- Security tool development
- Cybersecurity education

DO NOT deploy this application to production or expose it
to the public internet.

## Intentional vulnerabilities

- SQL Injection
- Cross-Site Scripting (XSS)
- Command Injection
- Hardcoded Secret
- Weak Cryptographic Hash
- Insecure Deserialization
- Debug Mode Enabled
- Vulnerable Dependencies

Each vulnerability is intentionally introduced and documented
for testing purposes.
